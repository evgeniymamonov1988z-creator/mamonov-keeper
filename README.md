# Ключница (Keeper)

Простой локальный менеджер паролей для Windows. Все пароли хранятся
в одном зашифрованном файле на вашем компьютере. Ничего
в интернет не отправляется.

© Evgeniy Mamonov — [evgeniymamonov.com](https://evgeniymamonov.com)

## Что умеет

- Хранит записи: название, логин, пароль, сайт, заметка.
- Защищает всё одним **мастер-паролем** — файл шифруется.
- Генератор надёжных паролей.
- Поиск по записям, копирование пароля в буфер одной кнопкой.
- Смена мастер-пароля.
- **Импорт из браузера** (Chrome, Edge, Яндекс.Браузер, Brave, Opera) —
  одной кнопкой втягивает сохранённые пароли (только Windows).
- **Экспорт для браузера** — сохраняет CSV, который можно
  импортировать в браузер через его встроенный «Импорт».

## Импорт и экспорт паролей

- **Импорт из браузера**: кнопка «Импорт из браузера». Работает
  только на Windows и под той же учётной записью системы (так
  устроено шифрование Windows DPAPI). Совет: закройте браузер
  перед импортом. Дубли не добавляются.
- **Экспорт для браузера**: кнопка «Экспорт для браузера» →
  сохраняет CSV. В браузере: настройки паролей → «Импорт» →
  выберите этот файл. ❗ CSV не зашифрован — удалите его сразу
  после импорта в браузер.

## Как защищены данные

- Файл хранилища — `%APPDATA%\MAMONOV\Klyuchnica\vault.dat`.
- Шифрование: **Fernet (AES-128-CBC + HMAC-SHA256)** из библиотеки `cryptography`.
- Ключ выводится из мастер-пароля через **PBKDF2-HMAC-SHA256, 200000 итераций**
  с уникальной солью. Сам мастер-пароль нигде не сохраняется.

> ❗ Если забыть мастер-пароль, восстановить пароли невозможно — такова цена надёжности.

## Запуск (простой способ, Windows)

Дважды кликните по файлу **`run.bat`** — он сам проверит Python,
при первом запуске доставит нужную библиотеку и откроет окно программы.

Если что-то не запускается — запустите **`check.bat`**: окно не закроется
и покажет причину ошибки.

## Запуск из исходников (вручную)

```bash
pip install -r requirements.txt
python keeper.py
```

## Сборка .exe (только Windows)

```bat
build_exe.bat
```
Результат — в папке `dist\Keeper\`.

## Состав

| Файл | Назначение |
|------|-----------|
| `keeper.py` | графическое окно (Tkinter) |
| `vault.py` | шифрование и работа с файлом хранилища |
| `pwgen.py` | генератор паролей |
| `browser_io.py` | импорт из браузеров и экспорт в CSV |
