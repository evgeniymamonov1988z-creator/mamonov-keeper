# Ключница (Keeper)

Простой локальный менеджер паролей для Windows. Все пароли хранятся
в одном зашифрованном файле на вашем компьютере. Ничего
в интернет не отправляется.

© Evgeniy Mamonov — [evgeniymamonov.com](https://evgeniymamonov.com)

## Что умеет

- Хранит записи: название, логин, пароль, сайт, заметка.
- Защищает всё одним **мастер-паролем** — файл шифруется.
- Генератор надёжных паролей.
- Поиск по записям, копирование пароля в буфер одной кнопкой.
- Смена мастер-пароля.

## Как защищены данные

- Файл хранилища — `%APPDATA%\MAMONOV\Klyuchnica\vault.dat`.
- Шифрование: **Fernet (AES-128-CBC + HMAC-SHA256)** из библиотеки `cryptography`.
- Ключ выводится из мастер-пароля через **PBKDF2-HMAC-SHA256, 200000 итераций**
  с уникальной солью. Сам мастер-пароль нигде не сохраняется.

> ❗ Если забыть мастер-пароль, восстановить пароли невозможно — такова цена надёжности.

## Запуск из исходников

```bash
pip install -r requirements.txt
python keeper.py
```

## Сборка .exe (только Windows)

```bat
build_exe.bat
```
Результат — в папке `dist\Keeper\`.

## Состав

| Файл | Назначение |
|------|-----------|
| `keeper.py` | графическое окно (Tkinter) |
| `vault.py` | шифрование и работа с файлом хранилища |
| `pwgen.py` | генератор паролей |
